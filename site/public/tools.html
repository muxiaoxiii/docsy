qpdf、Poppler、FFmpeg 是 Docsy 处理 PDF 和视频时使用的引擎。 按下面的对照表选择你系统的版本，从官方源下载；也可以直接在 Docsy 设置页一键安装。

风险提示

请只从本页列出的官方来源下载工具，不要使用来历不明的第三方打包版本。 下载后建议核对文件 SHA256 校验值；Docsy 自动安装时会强制校验。 使用第三方工具的风险由您自行承担。

如何安装到 Docsy

  1. 方式一（推荐）：系统安装

    macOS 用 Homebrew：brew install qpdf poppler ffmpeg，Docsy 会自动检测。Windows 可用 winget 或官方安装包。

  2. 方式二：Docsy 一键安装

    打开 Docsy 设置 → 外部工具状态，工具未安装时点击「下载安装到 Docsy」，由 Docsy 下载、校验并安装到工具目录。

  3. 方式三：本地安装（离线）

    下载本页的 zip 包，在设置页点击「本地安装」选择该文件；或解压后把可执行文件放入 Docsy 工具目录（设置页可见路径）。

文档转换工具（Word / WPS / LibreOffice）

Word 文件转 PDF 时，Docsy 优先使用 Microsoft Word，失败后使用 LibreOffice。 这些是完整办公软件，请从官方渠道安装：

  • Microsoft Word：microsoft.com
  • WPS：wps.cn
  • LibreOffice：libreoffice.org
