外部工具下载

基础 PDF 合并与拆分已内置。PDF 预览需要 Poppler，视频抽帧需要 FFmpeg；qpdf 用于复杂 PDF 的兼容处理和部分无损优化。可先在 Docsy 设置页检测，按需安装。

风险提示

请只从本页列出的官方来源下载工具，不要使用来历不明的第三方打包版本。 下载后建议核对文件 SHA256 校验值；Docsy 自动安装时会强制校验。 使用第三方工具的风险由您自行承担。

如何安装到 Docsy

  1. 方式一（推荐）：系统安装

    macOS 用 Homebrew：brew install qpdf poppler ffmpeg，Docsy 会自动检测。Windows 可通过 Docsy 设置页下载并安装组件。

  2. 方式二：Docsy 一键安装

    Windows：打开设置 → 外部工具状态，下载、校验并安装到 Docsy 工具目录。macOS：使用「终端安装（Homebrew）」安装到系统。

  3. 方式三：本地安装（离线）

    在设置页点击「本地安装」，选择适用于当前系统的工具包；请勿把 Windows 压缩包用于 macOS。

文档转换工具（Word / WPS / LibreOffice）

Windows 按 Microsoft Word → WPS → LibreOffice 的顺序尝试转换。macOS 使用 Microsoft Word，失败后尝试 LibreOffice；暂不自动调用 macOS WPS。自动转换失败时，可在办公软件中手动导出 PDF，再添加到 Docsy。请从官方渠道安装办公软件：

  • Microsoft Word：microsoft.com
  • WPS：wps.cn
  • LibreOffice：libreoffice.org
