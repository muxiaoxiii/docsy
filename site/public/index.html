文档转换与证据整理

把 Markdown 转成 Office 文档，把 PDF、Word 和图片整理成证据册。文档处理在自己的电脑上完成。

无需上传文档 无需把材料交给在线转换网站
免费开源 MIT 协议，可自由使用修改

从一段 Markdown，到一册证据

转换、编号、排版与拆分，覆盖常用文档工作。

Markdown 转换

粘贴文字或批量导入文件，生成 Word、Excel、PowerPoint 或 HTML。

  • Word 支持的公式可编辑，Mermaid 图以图片嵌入
  • Office / HTML 可提取为 Markdown；PDF 仅提取已有文本层

证据整理

PDF、Word 和图片一起编排，添加页眉页脚与连续页码，合并成可打印的证据册。

  • 图片可预览、旋转、缩放与手动裁剪后排入 A4
  • 按文件夹分别合并，或合成一份；拆分前核对页段

文书模板

在 Word 中标黄变量，建立填报模板；支持 Excel 数据批量生成文书。

PDF 工具

合并、拆分、提取页面、压缩、移除编辑限制与防复制处理；输出另存，保留原件。

图片排版

把照片、截图与扫描件排入 A4，调整行列、顺序、图注与边距，导出 PDF 或 DOCX。

视频抽帧

按时间范围、频率或间隔提取画面，筛选所需图片，按需添加时间戳水印。
