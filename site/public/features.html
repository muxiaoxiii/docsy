功能详情

深入了解 Docsy 的六大核心功能模块，每个都为你的文档处理需求精心设计

📝 文书模板

Word 标黄即生成模板，按字段批量填写，一次导出几十份文书。专为法律人、行政人员设计的文书批量生成神器。

  • 8 种字段类型，空字段自动清理
  • 历史填写记录一键复用
  • 跨模板推荐，同一字段自动带出
  • 基于 quick-xml 引擎，格式完整保留

📋 证据处理

页眉页脚智能检测、证据编号、合并拆分，律师整理证据一步到位。专为法律从业者设计的PDF证据整理工。

  • 三层检测，自动识别页眉页脚
  • 页码样式自由组合，连续编号
  • 支持独立PDF或合并PDF导入
  • 证据身份识别与设置

📄 PDF 工具

解锁、合并、拆分、压缩、提取页面，拖拽排序，处理完原样保留。一站式PDF处理工具箱。

  • PDF解锁与合并拆分
  • 页面压缩与提取
  • 拖拽排序，操作直观
  • 原样保留，格式不丢失

🖼️ 图片排版

照片、截图、扫描件批量排成整齐的 A4 文档，PDF 与 DOCX 双格式输出。让图片整理变得简单高效。

  • 批量图片自动排版
  • A4文档标准格式
  • PDF与DOCX双格式输出
  • 适合扫描件、截图等场景

🎬 视频抽帧

按时间范围或固定帧率截取画面，时间戳水印叠加，取证必备。视频内容提取变得简单。

  • 按时间范围截取画面
  • 固定帧率抽帧
  • 时间戳水印叠加
  • 取证与内容分析必备

🔄 Markdown 与 Office 互转

Markdown、Word 与 PDF 文本层双向转换，标题、表格、图片语义完整保留。让文档格式转换不再是难题。

  • Markdown ↔ Word 双向转换
  • Markdown ↔ PDF 文本层转换
  • 标题、表格、图片语义保留
  • 支持多种文档格式互转
