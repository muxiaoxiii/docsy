文档工作，顺手完成

从转换一段文字，到整理一整套材料。

Markdown 转成能继续编辑的文档

把 Markdown 粘贴进来，或批量添加文件，选择 Word、Excel、PowerPoint 或 HTML。标题、列表、表格和代码按输出格式组织。

  • Word 提供通用、法律文书与紧凑版式；支持的数学公式生成可编辑公式，其余回退为图片。
  • Mermaid 图以图片嵌入；Excel 和 PowerPoint 中的公式也以图片呈现。
  • 可复制富文本与纯文本，粘贴到邮件、聊天或编辑器；呈现效果取决于目标软件。

Office / HTML 可提取为 Markdown；PDF 仅提取已有文本层，不含 OCR、版面还原与表格识别。MD 转换页暂不导出 PDF。

把不同格式的材料，整理成一册证据

添加 PDF、Word 和静态图片，调整顺序，统一纸张与页码后合并输出。也可以扫描整个文件夹，按子文件夹分别生成文件。

  • 图片默认一页一图；预览时可拖拽合页、旋转、缩放、手动裁剪与调整行列。
  • A4 规范化将小页面居中补白，超过 A4 的页面才等比缩小；页眉、页脚、页码分别配置。
  • 文件夹内与文件夹间的双面补白分别设置；是否删除空白页由用户选择。
  • 合并证据拆分支持检测页段、核对命名后输出，原文件保留。

Word 转 PDF 调用本机办公软件；转换失败时，可手动转成 PDF 后补充到队列。页段检测结果需核对。

其他常用工具，也在这里

文书模板

在 Word 中标黄变量即可建立模板。支持结构化填写、历史记录回填，以及 Excel 数据批量生成。

PDF 工具

合并、拆分、提取页面、压缩、移除编辑限制与防复制处理。基础合并拆分已内置，复杂文件可调用 qpdf 兼容处理。

图片排版

将照片、截图和扫描件排入 A4，调整每页行列、顺序、图注与边距，导出 PDF 或 DOCX。

视频抽帧

选择时间范围、频率或间隔提取画面，筛选图片后导出。时间戳水印需 FFmpeg 对应滤镜支持。
