# Gemini Doclet 视频接入

原始三个 MP4 保持不动。应用使用离线去绿幕、去绿边、固定裁切后的透明动态 WebP（24 fps，320×400），不在运行时逐帧抠像，也不播放源视频的音轨。

- `22a52a2a`：待机、招呼、阅读、书写、惊讶、庆祝、等待。
- `077e946b`：完整 10 秒环顾。
- `8ac082e1`：抬头伸展、单眼眨眼、打哈欠。

素材位于 `src/assets/doclet-video/`，`manifest.json` 记录源文件、哈希与切片时间。用 `python3 scripts/prepare-doclet-videos.py` 可重新处理（需 FFmpeg、Pillow、NumPy）。

应用通过原有 `DocletSprite` 接入，各模块随处理状态选择动作。首页和模块点击随机播放动作，避免连续重复。

等待跟随使用“停留注意力”：鼠标在半径 40 px 的小区域停留 320 ms 才更新目标；小范围晃动取平均位置，快速扫过的地点丢弃。只选择稳定目标对应的实际姿态，起终姿态之间做 140 ms 淡化过渡；不沿视频时间线或二维中间点逐帧追赶。这是现有素材的过渡方案，不是新生成的转头动画。跟随图集只保留 119 个睁眼姿态；单 Canvas 每秒最多绘制 30 次，姿态稳定后停止刷新。离开窗口以相同短过渡回正。原视频没有覆盖的视角只能使用近似姿态。

完整环顾动画只供设计预览，保存在 `designs/assets/doclet-look-preview.webp`，不进入正式安装包。处理动作循环，招呼、庆祝和额外手势单次播放。页面不可见、滚出视口、组件停用或系统要求减少动态效果时切换静态图；素材失败回退原始精灵图。

`http://127.0.0.1:1420/designs/doclet-video-preview.html` 可检查全部动作及深浅色背景。AI 源视频本身的造型变化和动作衔接仍会保留，不代表重新绘制或生成素材中没有的背面视角。

真正的转头素材还需补齐：固定镜头、固定身体与光照，从同一正面基准分别看向上、右上、右、右下、下、左下、左、左上；每段 0.4–0.7 秒转向，末尾保持 0.5 秒，另配回正段。不要在一个片段中绕一圈，也不要夹入眨眼、道具或身体动作。所有片段的首帧、角色大小与地面位置必须一致。
