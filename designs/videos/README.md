# Gemini Doclet 视频接入

原始三个 MP4 保持不动。应用使用离线去绿幕、去绿边、固定裁切后的透明动态 WebP（24 fps，320×400），不在运行时逐帧抠像，也不播放源视频的音轨。

- `22a52a2a`：待机、招呼、阅读、书写、惊讶、庆祝、等待。
- `077e946b`：完整 10 秒环顾。
- `8ac082e1`：抬头伸展、单眼眨眼、打哈欠。

素材位于 `src/assets/doclet-video/`，`manifest.json` 记录源文件、哈希与切片时间。用 `python3 scripts/prepare-doclet-videos.py` 可重新处理（需 FFmpeg、Pillow、NumPy）。

应用通过原有 `DocletSprite` 接入，各模块随处理状态选择动作。首页和模块点击随机播放动作，避免连续重复。

等待跟随使用“停留注意力”：鼠标在半径 40 px 的小区域停留 320 ms 才更新目标；小范围晃动取平均位置，快速扫过的地点丢弃。新素材 `0218881e` 提供正面起步与四向回正；旧环顾 `077e946b` 提供相邻四个斜向短段，组合成八方向。旧片先按脚底基线向上平移 32 原始像素、横向平移 -1 像素，再拼接；去除其中闭眼区间。斜向回正仅逆用该短段后接新片实际回正，不倒放道具、招呼等完整动作。每次从正面出发，换向快速回正（约 100 ms），再转向最新目标（约 220 ms）；不排队、不沿旧视频整圈走。新旧素材和旧片闭眼跳段的接缝仅补间 45 ms，采用预乘像素相加，避免普通透明度淡化导致白色角色闪暗；换向不再额外插入另一张正面图。停稳后停止绘制。同一帧不重复绘制。117 帧图集为 2496×2160，约 0.85 MiB，解码约 20.57 MiB，比原始图集减少约一半。离开窗口回正。
完整环顾动画只供设计预览，保存在 `designs/assets/doclet-look-preview.webp`，不进入正式安装包。处理动作循环，招呼、庆祝和额外手势单次播放。页面不可见、滚出视口、组件停用或系统要求减少动态效果时切换静态图；素材失败回退原始精灵图。

`http://127.0.0.1:1420/designs/doclet-video-preview.html` 可检查全部动作及深浅色背景。AI 源视频本身的造型变化和动作衔接仍会保留，不代表重新绘制或生成素材中没有的背面视角。

新转向源文件与哈希、各方向切片帧号记录在 `src/assets/doclet-video/gaze-layout.json`，用 `python3 scripts/prepare-doclet-gaze.py` 可单独重建图集。旧视频继续承担点击动作与完整环顾预览；当前斜向是新旧素材短段拼接，源素材造型变化仍可能在交接处留下轻微差异。后续如补生成独立斜向，仍需保持同一正面首帧、角色大小、光照与地面位置。
