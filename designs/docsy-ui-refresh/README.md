# Docsy UI Refresh

High-fidelity interaction reference for the Docsy desktop UI refresh.

## Design source

- Existing Vue shell: `src/App.vue`
- Existing home screen: `src/modules/home/HomeView.vue`
- Existing global tokens: `src/styles.css`
- Existing brand assets: `src/assets/docsy-logo.png`, `src/assets/doclet-mascot-transparent.png`

## Direction

Quiet editorial workspace: a stable deep-green navigation rail, warm paper work area, low-radius geometry, restrained motion, and rust accents for position and focus.
