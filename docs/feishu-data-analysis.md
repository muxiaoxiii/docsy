## 核心发现

### 一、这是"专利无效/专利侵权诉讼管理"系统

| 维度 | 数据 | 含义 |
|---|---|---|
| 案由 TOP3 | 专利无效24 + 专利侵权11 + 专利行政9 | 80% 是专利案 |
| 审理机关 TOP3 | 国知局24 + 北京知产10 + 最高法8 | 专利无效归国知局，侵权归法院 |
| 专利字段 | 专利名称57/59、专利申请号57/59 | 几乎每案都有专利信息 |
| 公式期限 | 请求人补充意见/陈述意见等 8 个期限计算 | 全是专利无效法定时限 |

### 二、客户集中度高

从案件名称看：
- "隆基" 相关：至少 6 件（244号外观无效/侵权、46号二次无效、7号分案无效、7号母案无效、8号无效）
- "威灵电机"：至少 2 件
- "钛金"、"荣泰"、"同方威视"：各 1-2 件

**建议**：案件列表按客户分组，龙头客户快速展开全部关联案件。

### 三、三种时间压力

```
        已立案未判决（等待中）
        ┌─────────────────────┐
        │ 国知局无效口审 待排期 │  → 12件「待无效决定」
        │ 知产法院排庭 待开庭  │  → 3件「待开庭」
        │ 法院审理中 待判决   │  → 10件「待判决」
        └─────────────────────┘
        
        已开庭但结果未出
        ┌─────────────────────┐
        │ 收到判决时间=空       │  → 预估审限公式自动计算
        │ 但开庭时间≠空        │
        └─────────────────────┘
        
        法定期限逼近
        ┌─────────────────────┐
        │ 提交答辩状期间        │  → 收到起诉状+15工作日
        │ 请求人补充意见期限    │  → 提交补充意见+1月
        │ 专利权人陈述意见期限  │  → 收到受通+1月
        └─────────────────────┘
```

**建议**：首页面板三个区块——「等待判决」「近期开庭」「期限预警」。

### 四、庭审密度高

| 年份 | 庭审场次 | 趋势 |
|---|---|---|
| 2024 | 18 | - |
| 2025 | 37 | ↑ 翻倍 |

**开庭名称分布**：
- 无效口审 22 场（国知局专利无效的口头审理）
- 开庭 20 场（法院普通开庭）
- 第二次/第三次开庭 6 场（复杂案件多轮）

**建议**：日历视图用颜色区分口审(蓝)vs开庭(红)vs二审(黄)。

### 五、日志流转模式清晰

| 类型 | 数量 | 业务含义 |
|---|---|---|
| 交文 | 22 | 向法院/国知局提交文书 |
| 收文 | 18 | 收到法院/国知局文书 |
| 记录 | 16 | 工作记录（电话、会面等） |
| 任务 | 9 | 待办事项 |

**建议**：案件详情页用时间线展示「交文/收文/记录/任务」四种事件类型，不同图标。

### 六、公式字段 = 隐藏的提醒系统

8 个公式字段的计算逻辑高度一致：

```
模式：IF(AND(案由="专利无效", NOT(ISBLANK(触发日期))), 触发日期+N个月(工作日调整), "")
```

- `提交答辩状期间` — 收到起诉状 + 15个工作日
- `预估审限` — 立案 + 3/6个月 或 立案 + 5×30天（按审级和案由变化）
- `请求人补充意见期限` — 提交补充意见 + 1个月
- `请求人答复意见期限` — 收到专利权人意见 + 1个月
- `专利权人陈述意见期限` — 收到受通 + 1个月
- `专利权人补充意见时间` — 收到补充意见 + 1个月
- `案件状态` — 据案件结果自动判定"已完结/进行中"
- `距离截止日` — TODAY - 截止日期 → emoji 倒计时

**建议**：这些公式字段只填充了 1-2 条记录的数据。在本地版本中，公式引擎实时计算会比飞书公式更灵活（可以加 WORKDAY 调整、节假日排除）。

## 与 Docsy 模板系统的接入点

案件看板不应该是孤立的，它和 Docsy 的模板系统有三个天然连接：

1. **案件 → 一键生成文书**：从案件详情页点击"生成代理词"，自动用案件字段（当事人/案号/法院/案由）填充模板
2. **交文日志 → 文书归档**：日志类型=交文时，自动关联生成的 docx 文件路径
3. **期限 → 日历提醒**：公式引擎计算的期限自动进入日历视图，到期前弹通知

## 与飞书的关系

当前阶段：
- 飞书是数据源（已完整导出）
- Docsy 本地 SQLite 是主存储
- 不做双向同步（避免冲突）
- 后续可选：从飞书拉增量更新
