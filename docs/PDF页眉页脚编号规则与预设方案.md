# PDF 页眉页脚编号规则与预设方案

## 目标

在不推翻现有 `headerGroups`、`footerTextGroups`、`pageNumberGroups` 的前提下，完善接续编号、规则覆盖、分段例外和处理预设。

界面采用两层结构：

1. 一级规则列表和“高级设置”入口。
2. 单条规则的内容、编号、范围、样式和例外设置。

不增加独立的“编号来源”层。

## 编号继承

工作台保存一份全局编号默认值：

```js
{
  evidenceStart: 1,
  pageStart: 1,
  sequence: 'continuous',
  totalMode: 'combined',
  hiddenPagesCount: true,
}
```

规则通过 `numbering.source` 选择：

- `default`：跟随全局值。
- `custom`：只保存本规则覆盖的字段。

页眉规则使用证据序号；页码规则使用起始页码、连续方式、总页数和隐藏页计数。与当前规则无关的编号选项不显示。

## 高级设置

页码例外归入对应 `pageNumberGroup.exceptions`。例外只保存覆盖字段：

```js
{
  id: 'exception-id',
  scope: { type: 'global', start: 1, end: 1, fileIds: [] },
  overrides: { enabled: false, count: true }
}
```

字段不存在即跟随主规则；“恢复继承”通过删除覆盖字段实现，不保存主规则快照。

高级设置是本次处理的可执行设置，不是只读说明。它统一列出页眉、页脚文字和页码规则：页眉与页脚可限定文件和页段，页码还可设置接续编号、隐藏页计数及样式/位置覆盖。修改后立即进入普通预览、真实预览和最终生成。

旧页码组中的 `overrides` 在读取时转换为本组的 `exceptions`；新工作台不再维护独立的全局例外数组。

## 预设

规则列表上方提供：预设选择、应用、保存和管理。内置“新证据”和“补充证据（接续示例）”两套起点；应用补充证据预设后，用户直接修改本案的证据序号起始和页码起始，再按需另存。应用预设会改写当前工作台设置并用于本次文件，不是只展示预设内容。

预设保存所有用户配置：

- A4 规范化、纸张方向、内容旋转和安全边距。
- 批注删除和体积优化。
- 页眉、页脚文字、页码规则。
- 全局编号默认和规则级编号覆盖。
- 高级设置中的页段与例外。
- 书签、输出模式、文件后缀和合并文件名。

预设不保存输入文件、输出目录、检测结果及针对具体旧页眉页脚作出的决定。

同名保存必须确认覆盖。预设保存在应用内部存储中，并带 `schemaVersion`；加载时复制数据，不能与预设对象共享响应式引用。

## 执行规则

- 页码起始值通过规则的有效 `pageStart` 计算，不修改 PDF 文件的真实页序。
- 连续编号以合并后页序为坐标；单文件编号以文件内页序为坐标。
- 隐藏页默认仍计数；关闭后，隐藏且明确设置为不计数的页面不占编号。
- 总页数使用同一计数口径，避免正文页码与 `{total}` 不一致。
- 文件范围使用稳定文件 ID；预设中的文件引用无法匹配时必须提示，不按数组下标静默重绑。
