## 必须明确的验收边界

- 未进行 Windows x64/x86 真机安装、macOS 原生全流程交互验收、Word/WPS 的真实分页与裁字检查、真实 700+ 页及 100MB+ 扫描件端到端验收。
- 100MB 阈值只用稀疏文件验证分支条件；300/301 页夹具是合成文本页。旋转、CropBox、数字签名等复杂真实文件仍须抽验；任何重写都不能承诺保持数字签名有效。
- 未进行原生关闭重开、真实旧数据库升级、磁盘满或强制断电测试。设置备份和偏好迁移已有程序级回归；Windows 文件替换仍需原机验证。
- 局部比例的素材身份使用路径、尺寸、文件大小及分页。原路径被替换且元数据完全相同的图片无法靠这些字段识别为新内容，应重新设置本页比例。
- 分段会明确拒绝未支持的目录结构；这是保护结果完整性的功能限制。可用普通无损优化处理，或先在专业 PDF 工具中处理文档结构。旧防复制文件先恢复再优化。
- 文档转换、单张大图解码和最终打包/写盘步骤的停止不是即时抢占；停止后已明确完成的文件保留。
- 工具下载 URL 的长期可用性没有保证；本次没有制作跨平台离线工具包，也没有核查 GitHub 最新提交、远端 CI 或发布资产。

完成上述原生验收后，可在同一候选基础上确定最终停更发布；本次不会把本地构建描述为已公开发布。
