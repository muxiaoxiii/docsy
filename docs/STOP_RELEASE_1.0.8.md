### Word 自由排版后续建议

本轮没有切换为文本框。将来如需图片与文字独立拖动，应使用共享的页面几何模型（mm 坐标、框宽高、文本行、字体和行距），预览、PDF、Word 均消费同一结果；Word 的图片和原生可编辑文本框都使用相对页面的绝对锚定，关闭自动适应文字、正文环绕及单元格约束，并以稳定的每页锚点控制分页。仅替换文字而保留图片段落流无法保证对齐。必须另验 Word/WPS、长标题换行、缺字体、重开和改字，不能承诺跨渲染器像素级一致。当前表格／段落模式作为本轮发版实现。

## FFmpeg drawtext 安装反馈

本机 `/opt/homebrew/bin/ffmpeg` 为 Homebrew `ffmpeg 9.0.1_1`，滤镜列表无 drawtext，实际生成文字水印返回 `No such filter: drawtext`；未安装 ffmpeg-full。应用检测执行真实 `-filters`，不是按版本号猜测。根因是界面引导完整版，而终端单独／批量安装和后台 Homebrew 安装仍选了普通 ffmpeg。

已统一映射到 ffmpeg-full；终端安装成功后通过该 formula 的绝对路径实际运行一帧 drawtext，验证失败不显示安装成功。安装轮询对 FFmpeg 另查 drawtext，视频页补充重新检测、缺滤镜时的完整安装按钮、返回页面及窗口聚焦刷新。单帧验证及安装失败码有 shell 回归，前端检测更新有回归。本轮未替用户更改全局 Homebrew 安装；使用新版按钮或执行 `brew install ffmpeg-full` 后再检测即可。完整版的独立路径已在 FFmpeg 候选列表中，不需要强制覆盖普通版软链接。
