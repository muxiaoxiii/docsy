## 问题 12：导入流程优化

### 设计变更

**导入后不自动检测页眉页脚**，只检测页数。页眉页脚检测通过按钮触发。

- 导入后：只做 `get_pdf_page_count`（每个文件一次，秒级）
- 页眉页脚检测：通过"深度检测"按钮手动触发
- 不再区分快速/深度检测，检测就是完整的检测

### 模板变更

**删除**：导入时的检测进度 div（line 31）
```html
<!-- 删除这个 -->
<div v-if="detectingAllHeaderFooter" v-loading="true" ...>
```

**深度检测按钮**：
- `:loading` 改用独立的 `deepDetecting` ref
- 导入时不应转圈

### Doclet 动画

- 读取页数：改用 `tauriCallQuiet`（不触发 doclet）
- 检测页眉页脚：手动触发一次 doclet

### 首页特殊匹配

保持不变：证据X/对比文件X 序列直接作为候选。
